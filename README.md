### Grade Genie - Teacher's ERP for Attendance and Marks Management  

**Tech Stack**: HTML, CSS, JavaScript  

- **Attendance Management**: Designed an interface for marking and tracking student attendance.  
- **Marks Management**: Developed functionality for teachers to input and calculate student grades.  
- **User Dashboard**: Created interactive dashboards displaying attendance summaries and class performance.  
- **Responsive Design**: Ensured compatibility across devices using HTML, CSS, and JavaScript.  
- **Frontend Only**: Focused entirely on client-side features for seamless data entry and visualization.
